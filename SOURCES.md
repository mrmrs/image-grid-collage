# Image library sources

25 source images downloaded from Unsplash for local generative experiments. The JPEGs are stored locally in `public/images/`; the app needs no Unsplash API key or external image requests. The manifest includes original photo pages, verified photographer credits, download URLs, categories, original dimensions, and local dimensions.

Images use the [Unsplash License](https://unsplash.com/license), as recorded on each original photo page. Source metadata was retrieved on October 14, 2026. Downloads are resized to 2400 pixels wide (original aspect ratio), JPEG quality 90, sRGB. Smaller originals are not enlarged.

Re-download with `node scripts/download-images.mjs` (Node 20+). Higher-resolution source originals are available from the linked Unsplash pages for final print production. At 300 dpi, pixel count determines printed size; the exported print can be larger than the native image detail.
